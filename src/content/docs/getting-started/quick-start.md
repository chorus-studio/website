After [installing Chorus](/getting-started/installation/), here's how to start using it.

## 1. Open Spotify

Navigate to [open.spotify.com](https://open.spotify.com) in your browser and play any track.

## 2. Access Chorus Controls

There are two ways to access Chorus features:

- **Extension popup**: Click the Chorus icon in your browser toolbar
- **In-page controls**: Look for the settings gear icon on the Spotify player bar

## 3. Explore the Tabs

The Chorus interface is organized into tabs:

| Tab | What it does |
|-----|-------------|
| **Snip** | Save and loop favorite track sections |
| **Speed** | Adjust playback speed and pitch |
| **Seek** | Configure fast-forward and rewind durations |
| **EQ** | Equalizer with presets and custom profiles |
| **Reverb** | Room reverb effects |
| **MS** | Mid-side stereo processing |

## 4. Try Your First Snip

1. Play a track and find a section you love
2. Open the **Snip** tab
3. Set the start and end times for your favorite section
4. Toggle **Loop** to replay it infinitely

## 5. Keyboard Shortcuts

Chorus supports 20+ keyboard shortcuts. Set them up in your browser's extension shortcuts settings:

- **Chrome**: `chrome://extensions/shortcuts`
- **Firefox**: `about:addons` → gear icon → Manage Extension Shortcuts

See the full list in [Keyboard Shortcuts](/features/keyboard-shortcuts/).

## Tips

- **Pin the extension**: Right-click the Chorus icon and pin it for quick on/off toggling
- **Per-track settings**: Speed and audio effects can be saved per track
- **Presets**: Save up to 5 audio presets and switch between them with keyboard shortcuts
