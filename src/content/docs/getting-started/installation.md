Chorus is available for all major browsers. Choose your preferred installation method below.

## Chrome Web Store (Recommended)

Install directly from the Chrome Web Store. This also works for **Edge**, **Opera**, **Brave**, **Vivaldi**, and other Chromium-based browsers.

[Install from Chrome Web Store](https://chrome.google.com/webstore/detail/cdrani/jfnjmnapkhdbaidedlbdcmhiphfjljcd)

## Firefox Add-ons

Install from the official Mozilla Add-ons page.

[Install from Firefox Add-ons](https://addons.mozilla.org/firefox/addon/chorus-spotify-enhancer/)

:::note
The Firefox version may occasionally lag behind the Chrome version by a release or two due to manual publishing.
:::

## Manual Installation

If you prefer to install manually or want a specific version:

1. Go to the [GitHub Releases](https://github.com/chorus-studio/chorus/releases) page
2. Download `chorus-chrome.zip` or `chorus-firefox.zip`
3. For Chrome:
   - Navigate to `chrome://extensions/`
   - Enable **Developer mode** (toggle in top right)
   - Click **Load unpacked** and select the extracted folder
4. For Firefox:
   - Navigate to `about:debugging#/runtime/this-firefox`
   - Click **Load Temporary Add-on** and select the zip file

:::caution
Manually loaded extensions in Firefox are temporary and will be removed when Firefox is restarted.
:::

## After Installation

Once installed, head to [open.spotify.com](https://open.spotify.com) and you'll see Chorus controls appear on the player bar.

We recommend **pinning the extension icon** to your toolbar for quick access to the on/off toggle.
