---
title: Speed Control
description: Adjust playback speed globally or per track with pitch correction.
---

Control playback speed for any track with optional pitch correction to maintain vocal quality.

## Global Speed

Set a default playback speed that applies to all tracks. This is useful if you generally prefer slightly faster or slower playback.

## Per-Track Speed

Override the global speed for individual tracks. Per-track settings are saved and remembered each time you play that track.

## Pitch Correction

Toggle the **Pitch Correct** button to switch between:

- **On**: Vocals maintain their natural pitch at any speed (time-stretching)
- **Off**: Vocals shift pitch with speed changes (chipmunk effect at high speed, deep voice at low speed)

Pitch correction uses the SoundTouch audio processing library for high-quality time stretching.

## Speed Presets

Save frequently used speed values for quick access. Presets can be recalled via keyboard shortcuts.

## Use Cases

- **Podcasts & Audiobooks**: Speed up long-form content to 1.5x or 2x
- **Music Practice**: Slow down complex passages for learning
- **Language Learning**: Slow down lyrics for transcription
- **Casual Listening**: Fine-tune tempo to your preference
