title: Snips
description: Save and loop your favorite sections of any track.

Snips let you save your favorite section of any track — a chorus, verse, bridge, or drop — and loop it forever.

## Creating a Snip

1. Play a track in Spotify
2. Open the Chorus controls and navigate to the **Snip** tab
3. Set the **start time** by seeking to where you want the snip to begin
4. Set the **end time** where you want the snip to end
5. The snip is automatically saved for that track

## Looping

Toggle the **Loop** button to replay your snip section infinitely. When enabled, playback will automatically jump back to the snip start time when it reaches the end time.

You can toggle looping via keyboard shortcut as well (see [Keyboard Shortcuts](/features/keyboard-shortcuts/)).

## Sharing Snips

Generate a shareable link for any snip to share across social media or with friends. The recipient can hear the exact section you saved (they'll need Chorus installed).

## Per-Track Storage

Snips are stored per track. Each track can have one saved snip section. When you play a track with a saved snip, it will automatically seek to the snip start position.

## Tips

- Use snips to skip long intros or outros
- Combine with speed control for practice/study scenarios
- Snips work with all Spotify content types
