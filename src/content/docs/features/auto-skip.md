Auto-skip lets you block tracks so they're automatically skipped whenever they come up in any playlist, album, or queue.

## Blocking a Track

You can block tracks from multiple places in Spotify:

- **Now Playing bar**: Click the block icon in the Chorus controls
- **Album view**: Block individual tracks from the album tracklist
- **Playlist view**: Block tracks directly from playlist entries
- **Artist page**: Block tracks from artist discographies
- **Search results**: Block from search
- **Queue**: Block upcoming tracks in the queue

## How It Works

When a blocked track starts playing, Chorus immediately skips to the next track. The skip happens automatically — you'll barely notice the blocked track.

## Managing Blocked Tracks

Your block list is persistent and stored in your browser's extension storage. Blocked tracks remain blocked until you explicitly unblock them.

To unblock a track, find it in any context and click the block icon again to toggle it off.

## Keyboard Shortcut

You can block the currently playing track via keyboard shortcut. See [Keyboard Shortcuts](/features/keyboard-shortcuts/) for setup instructions.
