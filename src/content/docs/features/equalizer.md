The built-in equalizer lets you shape the frequency response of your audio with presets or custom curves.

## Presets

Chorus includes Spotify-style EQ presets covering common listening scenarios:

- Flat
- Bass Boost
- Bass Reducer
- Classical
- Dance
- Hip-Hop
- Jazz
- Latin
- Loudness
- Piano
- Pop
- R&B
- Rock
- Spoken Word
- Treble Boost
- Treble Reducer

## Custom EQ

Create your own EQ profile by adjusting individual frequency bands. Custom presets can be saved and recalled.

## Per-Track EQ

Save different EQ settings for different tracks. Chorus remembers which EQ profile to use when a track plays.

## Audio Presets

Save up to 5 combined audio presets (EQ + reverb + MS settings) and switch between them instantly using keyboard shortcuts (`Audio Preset 1` through `Audio Preset 5`).

## Technical Details

The equalizer is implemented using the Web Audio API's BiquadFilter nodes, providing real-time frequency adjustment with zero latency.
