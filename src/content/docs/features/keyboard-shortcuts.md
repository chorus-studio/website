Chorus supports 20+ keyboard shortcuts for controlling playback, managing tracks, and switching presets.

## Setting Up Shortcuts

Keyboard shortcuts are configured through your browser's extension settings:

- **Chrome**: Navigate to `chrome://extensions/shortcuts`
- **Firefox**: Go to `about:addons` → click the gear icon → Manage Extension Shortcuts
- **Edge**: Navigate to `edge://extensions/shortcuts`

## Available Commands

### Playback Controls

| Command | Description |
|---------|-------------|
| Play/Pause | Toggle playback |
| Next | Skip to next track |
| Previous | Go to previous track |
| Shuffle | Toggle shuffle mode |
| Repeat | Cycle repeat modes |
| Mute/Unmute | Toggle audio mute |

### Track Management

| Command | Description |
|---------|-------------|
| Save/Unsave | Toggle track in your library |
| Block Track | Add/remove track from block list |
| Show Track | Display current track notification |

### Snip Controls

| Command | Description |
|---------|-------------|
| Loop | Toggle snip looping on/off |

### Seeking

| Command | Description |
|---------|-------------|
| Seek Forward | Jump forward by configured duration |
| Seek Rewind | Jump backward by configured duration |

### UI Controls

| Command | Description |
|---------|-------------|
| On/Off | Toggle extension on/off |
| Settings | Open/close Chorus controls |
| Toggle Config | Toggle Chorus config UI |
| Toggle New Releases | Show/hide new releases panel |

### Audio Presets

| Command | Description |
|---------|-------------|
| Audio Preset 1-5 | Load saved audio preset (EQ + Reverb + MS) |

### Theming

| Command | Description |
|---------|-------------|
| Cycle Theme Next | Switch to next theme |
| Cycle Theme Previous | Switch to previous theme |

## Tips

- Not all shortcuts need to be assigned — only set up the ones you use
- Shortcuts work globally when the browser is focused
- Some shortcuts may conflict with browser or OS shortcuts — the browser settings page will show conflicts
