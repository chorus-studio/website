Customize the look of the Spotify web player with Chorus themes.

## Available Themes

Chorus includes multiple theme options. The default is the standard Spotify theme, but you can switch to alternatives that change the look of the player controls and UI.

## Vibrant Colors

One of the standout features is **vibrant color extraction**. When enabled, Chorus extracts the dominant colors from the current track's album artwork and uses them to dynamically style the player.

This means the UI subtly shifts colors to match whatever you're listening to — creating a personalized, immersive visual experience.

## Cycling Themes

Switch themes quickly using keyboard shortcuts:

- **Cycle Theme Next**: Move to the next theme
- **Cycle Theme Previous**: Move to the previous theme

See [Keyboard Shortcuts](/features/keyboard-shortcuts/) for setup.

## Dark Mode

Chorus respects your system's dark mode preference and integrates with Spotify's existing dark interface.
